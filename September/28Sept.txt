Fix component not loading properly: 1h
Due to React's lazy loading function, it resulted in a UX issue 
in which when a user enters a certain page, the user has to 
refresh the page for the component to fully load. Fortunately, 
this was fixed quickly and now the web application can load 
the component without the user refreshing.
